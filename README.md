## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/anujugale5889/my-portfolio.git
cd my-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Navigate to `http://localhost:3000` to preview locally.

### 4. Build for production
```bash
npm run build
```
Optimized static build output will be compiled to `dist/` with automated vendor chunk splitting.
